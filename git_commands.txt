# Git Commands for Release

# 1. Initialize git repository (if not already done)
git init

# 2. Add GitHub remote
git remote add origin https://github.com/abdurrhmansaeed/ColorRemover.git

# 3. Add all files
git add .

# 4. Commit with release message
git commit -m "ColorRemover v1.0 - Complete multi-platform release with GitHub Actions

- Professional Qt-based image color removal tool
- Bilingual interface (English/Arabic) with RTL support
- Automated builds for Windows, macOS, and Linux
- Windows installer and portable packages
- macOS DMG with drag-to-install interface
- Linux portable package with run script
- Complete documentation and build guides
- GitHub Actions workflows for automated releases"

# 5. Push to GitHub
git push -u origin main

# 6. Create first release tag
git tag -a v1.0 -m "ColorRemover v1.0 - Initial release

Features:
- Smart color removal with tolerance adjustment
- Real-time preview and zoom controls
- Multiple image format support
- Professional bilingual interface
- Cross-platform compatibility
- Automated build system"

# 7. Push the tag to trigger release build
git push origin v1.0

# 8. Monitor progress at:
# https://github.com/abdurrhmansaeed/ColorRemover/actions
